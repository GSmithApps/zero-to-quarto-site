## Install Visual Studio Code

- [ ] Install Visual Studio Code (usually called to "VS Code").
- Don't confuse it with "Visual Studio", which is different
- Free and doesn't require admin

## GitHub Account

Github is a website that's like Google Drive
mixed with a social network. Programmers use it to
keep and share their code.

- [ ] Make a GitHub account
- It's free and no spam etc

![Github Image](./images/github-me.png)
